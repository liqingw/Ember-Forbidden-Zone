# 2.0 主视觉生成记录

模式：内置 `image_gen`，全新图像生成。用户附图只作为风格与配色参考，没有作为编辑目标。

输出：`assets_raw/ashen_zone_v2_title.png`，经尺寸适配后用于 `assets/bg_title.png`。

最终提示词：

> Create a NEW original 16-bit pixel-art title background for a top-down action roguelite game called Ashen Exclusion Zone. Use the attached image ONLY as a style and palette reference: deep violet night, teal and electric cyan light, hot magenta neon, detailed pixel clusters, glowing polluted crystal energy, high-contrast cinematic atmosphere. Composition: a rooftop safehouse on the lower third overlooking a dense quarantined cyberpunk city at night; distant skyscrapers, broken elevated transit, drifting smog, turquoise searchlights, crackling crystal growths, a small lone armored survivor silhouette seen from behind at center-bottom. Rich microtextures, parallax-feeling depth, architectural detail. Leave the upper-center half relatively quiet and dark so game title and menu UI can be overlaid by code. No visible text, no logos, no UI, no copyrighted characters. Pixel art pixels crisp, no soft painting, wide 16:9 landscape composition.

局内精灵、武器和七套地形纹理由 `tools/generate_v2_art.py` 程序生成，生成规则与随机种子固定，可重复构建。
