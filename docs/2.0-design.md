# 《余烬禁区》2.0 设计与验收

## 目标

保留俯视角射击与既有七场景、35 关的线性流程，全面替换主视觉、场景纹理、角色、怪物与武器表现。参考用户图片的紫青洋红霓虹像素风，但角色、武器、地图均为原创。将课程 Word 文档中可用于俯视角游戏的手感、程序化关卡、缓存、手机适配和调试记录要求用于本作。

## 内容

- 32 种武器，近战与远程均有独立图标和弹道/伤害/节奏；七档品质仍按白绿蓝紫金红璀璨递进，高品质型号池逐级缩小。品质机制和满级效果沿用且扩充视觉反馈。
- 七个场景分别烘焙地面、变化砖和墙体纹理，房间背景缓存，保持可通行与碰撞设计。角色采用专属像素战甲；敌人按原有行为类别重新设计装甲与发光器官，首领有独立高细节造型。
- 发射、命中、近战、爆炸的粒子、光环与短暂震屏随武器参数变化。音乐、音效、震动仍默认关闭。
- 新标题主视觉、2.0 更新日志、游戏内说明、网页版、Windows exe、手机 PWA 交付。无实际付款、无账户注册、无公开发布。

## 兼容与风险

旧存档结构不改，2.0 新武器通过既有武器键和品质字段存储。网页版与桌面版在当前架构下共用 Python 数据导出，但绘制代码各有一套，须分别做数据、资源与运行测试。参考图是横版构图，只借鉴像素与灯光语言；用户已选择保留俯视角。

## 验收

资源完整性：32 个武器 PNG 文件且 SHA 各异；每个场景具备一组主题地砖；全部角色和基础敌人非占位。逻辑：武器数据与 JS 导出一致，高低品质池严格递减，旧存档可加载，原有进度/传送门/存档回归测试通过。交付：Web、Windows、PWA 包的版本号、资源与日志一致；桌面 exe 自检通过，PWA 注册与缓存通过。
