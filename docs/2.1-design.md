# 余烬禁区 2.1 设计

保留俯视角、旧存档和七个主题各五关的线性进度。常规武器品质从白色递进到红色，璀璨保留为隐藏掉落。新增到五十把基础型号；每把有独立贴图、数值、攻击节奏和特效标记，近战按扇形命中与击退结算。七个主题的小首领与大首领各用独立名称、图鉴条目与贴图。第三关首领有概率掉落主题金武，第五关首领有概率掉落主题红武，保留原有稀有图纸机制。

收集品独立图标；首次拾取产生短暂居中展示、光圈和音效，游戏状态继续自动保存。五类宝箱与五类陷阱使用分明轮廓；场景主题配色作用到房间纹理、陷阱与宝箱边饰。图鉴保留未发现条目的问号，已发现的武器和怪物显示主要属性。武器只在按交互键并二次确认后交换，避免路过时误换。

实现顺序：数据与规则测试、角色和怪物/物品图标、双端交互及展示、打包与浏览器/桌面自检。Windows、网页和 PWA 使用同一资源表；不做实际付费或发布。
