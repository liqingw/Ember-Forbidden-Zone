# 3.2 多端与触控设计

游戏逻辑继续以 `web_src` 为手机端和网页端的共同来源；桌面端沿用 Python 实现。构建时从同一份手机网页生成 PWA、Android 工程和 iOS 工程，版本号统一为 3.2。

手机画面固定 16:9。画布按屏幕可用宽高取连续缩放比例，并以屏幕中心放置；安全区域留给系统刘海和手势条。竖屏提示用户旋转设备，横屏尽量充满屏幕。

手机端仅使用指针事件处理菜单点击、摇杆、瞄准和虚拟按键。交互、换武器、技能采用待消费脉冲，短按也不能丢失；射击按住生效；暂停按钮可进入菜单。虚拟按键只在手机战斗时显示。帮助与提示文字根据当前输入模式分别显示，不混用键盘和触屏说明。

安卓与 iOS 均以本地 WebView 加载打包进应用的同一份资源，更新从同一构建脚本同步。安卓安装包需要 SDK、JDK 和签名；iOS 安装包需要 macOS、Xcode 与签名。当前环境没有 Mac，因此本机能准备 iOS 工程和测试网页逻辑，不能产出已签名的 iPhone 安装包。
