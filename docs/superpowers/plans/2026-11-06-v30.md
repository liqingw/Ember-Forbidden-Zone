# 3.0 Major Update Implementation Plan

**Goal:** Make one stage one map, let completed profiles replay from stage one, add 36 distinct weapons, a lucky treasure monster, visible upgrade costs, and richer original art on desktop and web.

**Architecture:** Keep existing Python data tables as canonical game data and regenerate browser tables from them. Preserve historical clear records while clearing the active run when a run settles. Keep three spawn waves inside combat rooms, independent of stage count.

**Tech Stack:** Python, pygame-ce, Pillow, JavaScript, Canvas, PyInstaller.

## Tasks

- [ ] Add regression checks for one map per stage and replay after settlement.
- [ ] Implement run reset preserving history in Python and browser; migrate old completed saves.
- [ ] Add five fixed-rarity weapons to each regular rarity and six radiant weapons, with separate icons, effects, sounds and radiant mechanics.
- [ ] Increase practical player damage and add a lucky treasure monster with rare drops.
- [ ] Surface all weapon upgrade material costs in the growth screen.
- [ ] Enhance original scene, hero and monster sprites with richer detail.
- [ ] Regenerate browser and art, build 3.0 deliverables, run logic, browser, executable and package checks.

## Constraints

- Do not delete files or folders without the user's explicit confirmation after a path and impact list.
- Keep existing player saves readable and preserve historical clear records.
- Preserve three waves of at least five monsters in combat rooms.
