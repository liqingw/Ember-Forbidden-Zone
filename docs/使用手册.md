## 零点五、开机没反应怎么办

如果双击 `陆面过程模拟.exe` 之后**屏幕上什么都没有**，请到 exe 同目录看
`boot.log` 文件。它按时间顺序记录了启动的每一步，例如：

```
[14:10:22] ---- 启动 v1.3.1 ----
[14:10:22] frozen=True  argv=['SoulKnightLite.exe']
[14:10:22] splash 已显示
[14:10:22] import Game 完成 0.022s
[14:10:22] Game 构造完成 0.567s  window=(1280, 720) scale=2
[14:10:22] 首帧渲染完成，窗口应已可见
```

- **看到「首帧渲染完成」** → 窗口已经出来了，若仍看不见请检查是否被
  其它窗口挡住、或显卡驱动异常。
- **日志停在某一行不动** → 那一行的**下一步**就是卡住的位置，
  把这个文件发出来即可定位。
- **完全没有 boot.log** → 程序根本没启动到我们的代码，
  多半是杀毒软件拦截，或 exe 被杀软隔离了。

> 正常情况下的启动速度：**约 2.5 秒**首帧可见（含解包）。如果你等超过
> 10 秒还没窗口，那一定是出问题了，别急着重启，先看 `boot.log`。

## 一、这是什么

一场「污染入侵」之后，地表只剩下零散的堡垒与不断向深处扩散的污染源。
你要做的很简单：**一层层往下打，活着回来。**

- **35 个关卡** = 7 个主题场景 × 5 关
  - 4 个主线场景（由浅入深的污染梯度）
  - 2 个副本（满足隐藏条件后解锁）
  - 1 个奖励延续副本（用金币购买入场）
- **7 档武器品质**、**18 个天赋**、**20 种敌人**、**10 件收集品**
- 每局随机生成地牢，死亡即重来，但**图鉴、收藏、金币与钻石会保留**

| --- | --- |

## 三、流程与推进

### 3.1 客厅

主菜单选「开始游戏」进入**客厅**，这里是出发前的准备界面，分三页（`TAB` 切换）：

1. **关卡**：列出全部场景。`↑↓` 选择，`E` 展开详情。
   - 副本会显示解锁条件（逐条打勾），以及一张「场景机制卡」
   - 「奖」标记的是奖励副本，需付金币购买入场
2. **图鉴**：怪物 / 武器 / 材料 / 收集品四类。`←→` 切分类，`↑↓` 翻条目。
   在关卡里遇到过就会自动收录，未发现的显示 `？？？`
3. **展示台**：6 个格子，摆放你收集到的工艺品。`←→` 换格子，`E` 取出/放回。

按 `Enter` 从当前选中的场景出发。

### 3.2 一关的结构

一个「场景」有 **5 关**（第 5 关是 BOSS 关），每一关内部有 **3 个房间**：

```
进场过场 → 房间 1 → 房间 2 → 房间 3 → 天赋三选一 → 下一关过场 → ……
```

- 房间里可能有：普通怪、精英怪（紫色描边）、陷阱、掩体、奖励洞穴、宝箱、商店
- 打完最后一个房间会弹出**天赋三选一**
- 第 5 关打完出现传送门，进入该场景最深处

### 3.3 存档

- 每通关一关自动存档；客厅里的金币、钻石、图鉴、收藏都会持久化
- 存档按角色名隔离，可开多份进度

## 四、核心系统

### 4.1 货币

| 货币 | 获取 | 用途 |
| --- | --- | --- |
| **金币** | 击杀、宝箱、木箱、金钥匙折算 | 商店、奖励副本入场 |
| **钻石** | 首领（必掉）、深层精英（概率） | 稀有种子的购买 |

持有上限：金币 99999、钻石 9999。**到达上限后不再增加**（屏幕会提示「已满」）。

### 4.2 天赋

每次过关三选一，选择会**整局保留**；同一天赋最多叠加 3 次。共 18 个：

- **数值类**：伤害、射速、生命上限、移速、能量上限、回能、暴击、冲刺、拾取范围、幸运、贯穿
- **机制类（flag）**：反伤甲、汲取、崩解弹、应急护盾
- **抗污染类**（v1.3 新增）：
  - **滤芯装甲**：污染侵蚀与减益整体 −25%（乘算，硬上限 85%）
  - **净化循环**：每 6 秒清除一次侵蚀累积
  - **污染共鸣**：污染浓度每 10%，伤害 +3%

### 4.3 污染（v1.3 重点）

污染浓度**随场景与关卡递增**，从地表 3% 一路到 96%。效果按「相对基准」计算
（每进一个场景重推一次，所以天赋加成不会被反复叠加或抹掉）：

| 效果 | 说明 |
| --- | --- |
| 生命上限削减 | 浓度越高，最大生命越低 |
| 移速下降 | 走位变得更难 |
| 回能下降 | 射击资源更紧张 |
| 持续侵蚀 | 每秒扣血，是长期压力来源 |

**抗污染天赋在这里是乘算减免**，堆满后最多削掉 85% 的减益 —— 越靠近源头，
这类构筑越值钱；在浅层几乎用不上，形成「环境越深、构筑越针对性」的取舍。

### 4.4 副本

副本不是靠等级解锁，而是靠**具体玩法条件**：

- **矿井**：累计击杀达门槛、且踩陷阱次数不超过上限
- **赐福**：完成主线最后一个场景后开放

条件在前置场景里都拿得到，详情面板会逐条打勾告诉你还差什么。
奖励副本则需付金币购买入场，属于纯收益的回补关卡。

### 4.5 图鉴与收藏品

- 四类图鉴：**怪物 20 / 武器 6 / 材料 8 / 收集品 10**
- 首次遇到自动收录并弹提示
- 宝箱有 35% 概率开出**收集品**（22% 为精品）
- 收集品自动上架展示台，可在客厅第 3 页整理摆放

## 六、常见问题

**Q：卡住了 / 掉进墙里怎么办？**
A：游戏内置防卡死：连续零位移会自动脱困。真遇到异常可 `ESC` → 重新开始。

**Q：音效没声音？**
A：默认静音，按 `M` 或在主菜单切换。

**Q：手机怎么玩？**
A：网页版检测到触控设备会自动显示半透明摇杆。建议横屏、全屏。
也可按 `手机版/README.md` 把它装成 PWA 应用。

**Q：想给朋友玩？**
A：直接发 `网页版/陆面过程模拟.html` 这一个文件，对方双击即可。
